Before you read the numbers

Almost every new token dies. Of all the ones we see, more than 99% die within a day, whatever we say. So “99% of the red ones died” doesn't prove much on its own: it has to be compared with that base rate, which is always the first row.

What really shows whether SolFlag is useful: the ones still alive (the misses, below, one by one), how many we mark green (almost none yet: minutes-old tokens rarely have reasons for green) and, later on, who is behind each launch, which is what a chart can't show.

Dead = at that point it is worth less than $10,000, RugCheck flags it as a rug, more than 95% of its liquidity was pulled or, off the Pump.fun curve, it has less than $1,000 of liquidity left or less than 0.2% of what it claims to be worth (it can't be sold).

Download the data

One file per launch day (UTC date) and an index with the summary. They are JSON. Each day is published twice: when all its tokens have the 24 h result and, closed, when they have the 7-day one.

    Format (version 1)

    Each day file is { v, day, final, updated, tokens }, and tokens is an object keyed by token address. Short keys because the registry grows every day:

    m
    token address (mint)
    s
    symbol
    t
    when it was created (ms since 1970, UTC)
    d
    dex where we saw it
    p
    launch platform according to RugCheck
    a
    when SolFlag analyzed it (ms)
    l
    level at first sight: HIGH, MEDIUM, LOW, SPAM, NO_DATA, NO_MARKET
    v
    severity (number)
    ty
    token type
    f
    signals that did not pass: “CODE:b” red, “CODE:w” yellow, “CODE:n” not checked
    liq / mc
    liquidity and market cap at first sight (USD)
    w1 / w10
    % held by the largest wallet and the top 10 (people)
    py / fu / cr
    who paid for the launch, who funded it and who created it
    rug
    RugCheck flags it as a rug
    cara
    known-face level, if any
    nrc / rcl
    RugCheck did not answer at first sight / answered later and p, cr, fu and rug were filled in
    ev
    engine version that analyzed it (no ev: 0.4.6)
    h24 / d7
    result: { mc, liq, dead, cv, pull, dry, dx, gr } (cv still on the curve, pull liquidity pulled, dry no liquidity or almost none next to its market cap, dx main dex, gr graduated from the curve)

    The index is { v, updated, days }; each day has levels and sig (by level and by signal: n, h24, dead24, d7, dead7), curve (curve tokens and how many graduated), alive (the ones alive) and final. If anything changes in an incompatible way, v goes up.

    These are facts visible on the chain (who paid, who funded, how it ended), never labels like “scammer”. If an address is yours or you think something is wrong, write to solflag.team@gmail.com: we check it and, if it is a mistake, we fix it and say so on the blog, as we already did with the 31/10 numbers.

    On 31/10 from 01 to 15 h UTC RugCheck did not answer and many tokens were left without creator or platform: that day has more “medium risk” than usual and the creator signals count for less.
